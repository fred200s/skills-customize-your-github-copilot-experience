# 📘 Assignment: Build a Simple Task Tracker Web App

## 🎯 Objective

Create a browser-based task tracker that lets users add, view, complete, and remove tasks. This assignment helps students practice HTML, CSS, JavaScript, and connecting a front end to a REST API.

## 📝 Tasks

### 🛠️ Create the page layout

#### Description
Build a simple web page with a form for adding tasks and a list that displays the current tasks.

#### Requirements
Completed program should:

- Show a title and a task input field
- Display tasks in a clear list on the page
- Include buttons for completing or removing tasks
- Style the interface so it is easy to use

### 🛠️ Connect the UI to an API

#### Description
Use JavaScript to communicate with a task API so tasks can be loaded, created, updated, and deleted.

#### Requirements
Completed program should:

- Use fetch to get tasks from an API endpoint
- Send new tasks to the server when the form is submitted
- Update the page after a task is added, completed, or deleted
- Handle loading and error states gracefully

### 🛠️ Polish the experience

#### Description
Make the task tracker feel complete by adding a few small touches.

#### Requirements
Completed program should:

- Show whether a task is complete or still pending
- Keep the page responsive and readable on smaller screens
- Provide clear feedback when an action succeeds or fails
